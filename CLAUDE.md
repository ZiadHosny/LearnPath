# Project instructions for Claude

## Git

- Never run `git commit`, `git merge` or `git push` without asking first and getting an explicit yes.
  Finish the work, show what changed, then ask (e.g. "Commit and merge into master?").
- Each commit, merge or push needs its own yes; approval for one does not carry over to the next.
- Spec Kit's `/speckit-git-commit` hook suggestions are only suggestions: still ask.
- Reading git state (`status`, `log`, `diff`) is fine without asking.
